# Sample Logs for Analysis UI

Use these files from the **File** tab on `/analysis`.

## Files

- `single.json`: Single JSON object for quick parse/store checks.
- `events.jsonl`: Multi-line JSON Lines input. Enable **Batch** for best results.
- `nginx.log`: Nginx access log lines.

## Quick usage

1. Open `/analysis`.
2. Switch to **File** tab.
3. Upload one sample.
4. For `events.jsonl`, enable **Batch**.
5. Enable **Store** only after parse succeeds.
